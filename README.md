# E-comerc 2025

Proyecto personal para expandir mis habilidades full stack


## 📌 Descripción

Este proyecto personal que busca ampliar y practicar mis conocimientos sobre distintas tecnologias en el ambito de desarrollo full stack

Además, se implementó una base del sistema utilizando TypeScript con NestJS para el backend, React y Tailwind para el frontend, y PostgreSQL como motor de base de datos.

## 🧑‍💻 Tecnologías utilizadas

- **Lenguaje:** TypeScript
- **Framework Backend:** NestJS
- **Base de Datos:** PostgreSQL
- **Frontend:** React + Tailwind
- **Modelado UML:** Enterprise Architect/StarUML
